## Item 1 — `rad_dual` (spontaneous dual intake)

### Theory
Claude qgraph coarse dual of radiance (`theory/qgraph/docs/UNIFIED_LAW.md` §3.3):

```
O = k_rad * cap * x^p                 (adopted outtake; x = Em/cap)
I = k_rad * cap * ( xb^p + g·x^(p−1)·xb )   (full dual)
```

With **g = 0** (spontaneous only — what was implemented):

```
I = k_rad * rad_dual * cap * xb^p     (xb = Ee/cap)
```

As **coded**, balance of O = k cap x^p against I is  
`x* = rad_dual^{1/p} · xb` (equals `xb` only at **rad_dual=1**, which is what
the suites ran). Claude Theorem 3.4 (`x*=xb`) assumes dual strength = 1.

**Code asymmetry (review M3):** both O and I use dense-clock compensation
`comp = w2/w2e` even though I’s source is the field; atom grain *is* swapped
(field source / dense dest). So the coded I is “same (k,p)” but not a perfect
time-dual of O. Redesign should revisit `comp` and core-cell x vs xb (not Em_tot).

Detailed balance at mode grain (L4) forces Boltzmann factor symbolically
(`maxima/detailed_balance.mac`; Go tests green). The **g** stimulated term
(Theorem 3.5, coherence lifts x\* above xb) was **not** coded.

### Code
- Knobs: `RadDual` default 0; parse `rad_dual` — `fab/params.go`.  
- Pass-6 after radiance, both kernels:  
  - Go: `fab/step.go` (~1432–1505): if `KRad>0 && RadDual>0 && Em>0 && Ee>0`,  
    `di = KRad*RadDual*Cap*pow(Ee/Cap, PRad)*comp`, atom fire/clamp, reverse
    radiance bookkeeping (shrink fa, Es reverse-backs, Em += di).  
  - C: `kernel/freecell.c` same placement.  
- Em>0 gate: no vacuum minting (workfn-safe).  
- Ledger: `radInTotal` / `rad_in_total`.  
- Battery: default 0 ⇒ inert on V3a surface; **p2fix2 ALL GREEN 87**.

### Numerics

`bath_xb∈{0.3,0.6,1.0,1.5}` × `rad_dual∈{0,1}`, T=600. All arms **box-fill**
(Em 2k–6k, nHot 1.3k–2.6k). Dual ratios Em_d1/Em_d0: 1.08 → 2.74 with xb.

**B. Quiet apparatus** (`p2quiet_T5000_*`, `P2QUIET_T5K.md`):
