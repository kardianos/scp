## 0. What “literal Bohmian” means (short, standard)

Bohmian mechanics (de Broglie–Bohm, pilot-wave theory):

1. **Wave is real** — a ψ on configuration space, evolves by Schrödinger
   (unitary, interferes).
2. **Beables are real** — actual point configurations Q(t) (particle
   positions), always definite.
3. **Guidance equation** — the wave *pilots* the beables:
   ```
   dQ/dt = v^ψ[Q] = (ħ/m) Im( ∇_Q log ψ ) |_{Q}
         = j/ρ   (probability current / density)
   ```
4. **Born rule** — if Q is |ψ|²-distributed at one time, it stays so
   (equivariance). Measurement outcomes look quantum without collapse
   *of ψ*; the effective collapse is of the *conditional* wave of
   subsystems.
5. **No classical force from ∇V alone** — trajectories feel the wave’s
   phase geometry (sometimes packaged as a “quantum potential”
   Q_B = −(ħ²/2m) ∇²R/R for ψ=R e^{iS/ħ}).

So Bohmian is **wave + guided corpuscles**, not “cells that are little
harmonic boxes.”

## 2. “Cells are too rigid” — the real complaint

A free-cell is a **finite roster element** with:

- a lump of Em, Es, Ee,
- clocks / phases,
- a radius and contacts,
- birth/death, but while alive a **discrete identity**.

That is rigid relative to Bohmian continuum in several ways:

| rigidity | symptom in v93 |
|---|---|
| **Support quantization** | phase slips when \|ψ\|→0 on a cell (item 4); winding needs whole-cell cycles |
| **Contact graph** | dephasing ~10 t.u. from discrete random contacts (Face B) |
| **Hop Trotter** | sequential Givens order breaks C6 (Face A) — discrete update artifact |
| **Em as scalar bag** (pre-U) / polar pair (U) | no sub-cell configuration; harmonics are *per cell*, not continuum modes in a well |
| **Door atoms** | conversion at cell grain, not continuum density response |

**[YES]** If “electron shells as unbound harmonics” need continuous nodal
structure inside a proton-scale object, a **one-phase-per-cell** Em store
is too coarse. Bohmian language names what is missing: **degrees of
freedom of a configuration inside the wave support**, not only the
wave’s energy.

## 3. Three ways to combine field-as-matter with Bohmian ideas

### 3.1 H3 — Re-reading only (cheapest, no ontology change)

Treat already-present quantities as Bohmian vocabulary:

```
ψ_field , ψ_dense     ↔  pilot waves (two sectors)
J_link                ↔  guidance current (discrete)
Em = |ψ_m|²           ↔  |ψ|² density (not a particle)
door clicks           ↔  effective “detections” (atoms), not Q hits
```

**[YIELD]** Better intuition for shear genesis (guidance current
convergence → condensation), for L1-A (fd is j), for why random phase
kills structure (scrambled v^ψ).  
**[COST]** Zero new physics; does not soften cell rigidity.  
**[YES]** Do this freely in theory notes; no kernel.

### 3.2 H2 — Soft beables (Bohmian method, free-cell legal)

Add **auxiliary configuration markers** that:

- are **guided by** existing J / ∇φ,
- **carry no energy** (or carry only a tracer label),
- **are not the conserved substance**,
- **die when support dies** (no immortal particle roster),
- exist to *sample* the wave the way Bohmian trajectories sample |ψ|².

Examples:

| soft beable | guidance | use |
|---|---|---|
| **Tracer points** in continuous embedding of the jam | dX/dt ∝ reconstructed v^ψ from neighbor J | screen statistics, “where would a corpuscle go” without being Em |
| **Parcel labels** on in-flight field/dense** | already half-present as flight phase; promote to guided sample | P2 / first-moment diagnostics |
| **Conditional phase defects** | defects advect with J, annihilate in pairs | continuous-ish topology without multi-cell rings only |

**[YIELD]**

- Test Born equivariance *inside* the sim with explicit samples.
- Probe whether “shells” can be **standing patterns of beable density**
  in a well of Es, while Em is only the source of the well — softens
  “one harmonic per cell.”
- Shear genesis: beables converge where J compresses; condensation
  rule can *read* beable density as a rate modifier (still energy from
  field book).

**[COST]**

- Must not let tracers become a background census.
- Must not conserve “tracer mass” as physics mass.
- Easy to fool yourself that tracers *are* electrons.

**[FORK]** Instrument-only first (tracers never back-react). Back-reaction
only later, and only if a bar demands it.

### 3.3 H1 — Literal Bohmian matter (hard revision)

Promote beables to **the matter**:

```
ψ = field (and maybe space-coupled) pilot on the free geometry
Q_a(t) = actual “corpuscle” configurations = matter
Em emerges as coarse-grain of Q-statistics or is retired
```

Guidance from ψ; conversion door becomes **creation/annihilation of
beable number** or coupling of ψ amplitude to Q population.

**[YIELD] — the attractive story**

1. **Sub-cell structure** — many Q’s inside one wave packet ⇒ shells,
   orbitals, nodal surfaces without one-clock-per-cell rigidity.
2. **Unique size** — bound state = equivariant cloud of Q’s in a
   self-consistent ψ well; size from guidance + interaction, not only
   radiance tax on Em hoards.
3. **Non-melting while radiating** — ψ can radiate (field sector) while
   Q’s continue to be guided in a bound equivariant state (classic
   Bohmian atom picture: electron positions orbit-ish under ψ that
   solves a stationary problem). **This is the closest standard
   ontology to “emits but doesn’t evaporate.”**
4. **Shear / genesis** — ψ shear changes v^ψ; Q’s stream and cluster;
   clustering can source nonlinear feedback into ψ (if allowed) ⇒
   matter appearance as **beable concentration**, not only Em deposit.
5. **Double-slit** — corpuscle goes through one slit; ψ through both;
   screen hit where Q arrives; Born from equivariance — already
   almost the story REALITY wants, made explicit.

**[COST] — the bill**

1. **Trajectory ontology returns** — direct conflict with “nothing has
   a trajectory.” Must rewrite PRINCIPLE or confine trajectories to
   “beable fiction of conversion.”
2. **Configuration space** — true multi-beable Bohmian is on R^{3N},
   not on the free-cell mesh. N-body pilot wave is a different
   computational object than per-cell (fa1,fa2).
3. **What is energy?** — today Em+Ee+Es is the ledger. If Q’s are
   matter, is energy in ψ only (Bohmian usual: energy in the wave /
   Hamiltonian), or do Q’s carry Em? Double-counting risk.
4. **No-background** — a fixed N of particles is a background census.
   Genesis/annihilation of beables is possible but then Bohmian is
   no longer standard (variable-N pilot wave / QFT Bohmian — hard).
5. **Battery** — every Em-based bar (hoards, radiance x^4, cap, pair
   locks) needs re-expression in (ψ, Q) language or dual-tracking.

**[TENSION]** H1 is a **programme fork**, not a knob. It should not be
sneaked in as “just tracers that back-react a little.”

## 9. Bottom line

Combining “field as matter” with **more literal Bohmian mechanics**
splits into:

- **Re-reading** — already half true; unifies shear, currents, Born.
- **Soft beables** — softens cell rigidity *as instrumentation* for

  drop-in v93 face.

The rigidity complaint is fair. The highest-leverage move that respects
the ontology is: **treat transport as guidance of amplitude (and optional
tracers), keep energy in the Em/Ee/Es ledger, and do not smuggle
immortal corpuscles under the name of harmonics.**

Shear genesis remains the cleaner empirical attack on *creation*.
Bohmian hybrid is the cleaner *language and instrument layer* for
*structure inside the wave* — complementary, not a substitute, and not
a license to abandon conversion-first ontology without an explicit fork.

## 10. Clarification: methodology, not beables — morph of the cell (2026-08-08)

User correction (binding for this note):

> Bringing in Bohmian is **not** adding a background, nor any other
> fundamental ontology change. It is **methodology / computation**, with
> harmonics perhaps more **line-like or progressive** than cell-bag-based.
> These are **not tracers per se**, but a **morph of what we understand a
> cell to be**.

The H1 “literal particles” and H2 “tracer corpuscles” readings above are
**side paths**. The intended center is **H0: recompute the cell**.

### 10.1 What stays fixed (ontology)

| fixed | meaning |
|---|---|
| No background | no immortal stage, no fixed-N particle census |
| Energy modes | Em / Ee / Es still the books |
| Conversion | doors, atoms, radiance — still how modes change |
| Free roster | things can still be born, die, jam, repack |
| No imported species | no electrons-as-new-field |

Bohmian here does **not** add a second substance. It changes **how the
existing substance is represented and stepped**.

### 10.2 What morphs (methodology)

Today’s default mental model:

```
cell  =  little rigid capsule
         owns Em, one clock th2, two field planes
         harmonics "live inside" the capsule
         contacts exchange between capsules
```

Morph (Bohmian-methodological):

```
cell  =  a local chart / sample of a progressive amplitude
         harmonics are line-like: they live along contacts, paths,
         and current lines — not sealed in a box
         the "object" is the coherent progression of phase and
         density (guidance of the amplitude pattern), not the
         integer id of a roster slot
         roster slots remain computational support, like a moving
         mesh — not the identity of matter
```

That is exactly why tagged-centroid translation failed (item 2): we
metered **capsule IDs**, while the physics already moved as a
**progressive pattern**. Bohmian methodology says: compute and meter the
pattern the way guidance theory computes ρ and v^ψ, even though the
implementation still sits on free cells.

### 10.3 “Line or progressive” harmonics — concrete readings

None of these require new ontology; they are computational framings:

| reading | already near | morph |
|---|---|---|
| **1-chain / slot harmonics** | slots carry flight, phase, registry | phase and current are **edge-primary**; cell values are integrals/samples of lines |
| **Path-progressive phase** | Givens hops, closure charts, ring winding | a harmonic is a **consistent progression of phase along a path** (∫∇φ · dl), not a property sealed in one Em bag |
| **Madelung / guidance step** | pass F, pass U | update as ρ and v= j/ρ (or discrete Givens that *realize* that), think in streamlines of amplitude |
| **Object = level set / support of pattern** | hoard, ring cycle | “the particle” is the **connected progressive structure** (where phase is locked and current closes or streams), while cells under it churn |
| **Shells** | Es well + field modes | outer harmonics = **progressive field lines / nodal progressions** in the well, not extra cells of a new type |

“Line-like” ≈ **DEC/link native** (v93 README already flirts with this).  
“Progressive” ≈ **identity through succession of structure along the
current**, not through permanent cell membership — PRINCIPLE’s own
“identity is succession,” computed more honestly.
