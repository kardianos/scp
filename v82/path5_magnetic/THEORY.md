# Approach B — magnetic / angular scale

## Thesis

A uniform (or slowly varying) \(B_z\) sets a cyclotron scale \(\omega_c = |q|B/m\). Relative orbit may lock to a preferred radius / frequency if medium radiation and soft core allow. Does **not** replace a short-range wall if Coulomb collapse is free; tests whether gyration alone parks multi-rev.

## Reduced picture

For opposite charges in \(+B_z\), Lorentz forces curve both trajectories; relative motion can gyre. With soft core only (no capacity), seed impact parameter \(b\) and \(v_t\).

Observable: joining-line revs, min sep, COM drift.

## Kill

All seeds expand, collapse-through, or revs≪1 with no sep band → magnetic alone insufficient (expected if no wall).

## Note

Magnetic sets **frequency** more easily than **radius**; if fail, still useful as *support* after capacity well exists.
