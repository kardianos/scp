## How to read the Face C histogram

Connected-component `N` on Face C is **not** the 189-hoard
cell histogram. It is one (sometimes two) giant live-Em
component whose `N` walks around 600–900, plus many
`N=3,4` crumbs. That is still *broad*: there is no single
compact `N` that holds the mass. The crumbs are not a
species line (they sit at the census floor). The giant is
not a species line (`N` walks, `N_eff/N ~ 0.64`).

This matches v97 H0 (“census is connected, max a handful of
motifs, not 189 hoards”) and the charter’s “hierarchy, not
a line.”

## How to read the C6 line

The vacuum ring is the existence proof that this meter *can*
see a line: one `N`, `N_eff = N`, Laplacian book exact, Em
parked. v97 already said that object is the wrong topology
for a particle (a loop). Phase 2 does not promote it. It
only checks that a line, when present, is visible.

## How to read the tax ceiling

the `N` histogram spread. It does not collapse onto a
compact `N`. That is MONO_FINAL, now on the size meter
