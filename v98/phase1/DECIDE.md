## 1. What was asked

The charter (`../README.md` §IV, Phase 1C) named four possible
endings:

| ending | condition | consequence |
|---|---|---|
| A | 1A already forces a line | 1B is the geometry of that line; no new substrate |
| B | 1A is a continuum | 1B is the first authorized new substrate |
| C | 1B cannot state a trough without importing `V(ρ)`, **and** 1A has no unique lock | **stop** |
| D | 1U finds a measured fact any lock-of-field would contradict | that fact vetoes a substrate before code |

Exactly one ending may be claimed. Softening a condition to
claim A, or inflating a named joint reading into a derivation,
is a miss.

## 2. What the three arms actually returned

**1A.** Cycle-closure (C1–C3) has a unique *smallest* simple
graph (`K₃`) and then a **zoo** (1, 3, 11, 60, 502 types at
`n = 3..7`). Sizes are discrete. They are not unique. The
measured filter F-odd moves the smallest to `C₄`. F-odd plus
3-connected moves it to `K_{3,3}` and leaves only `K_{3,4}`
at `n = 7`. That near-line **breaks at `n = 8`**. 1A does
not force a species.

**1B.** Continuum 3+2 kinetics have **no trough** (Maxima:
scale-invariant fiber Dirichlet energy; area and log-IR both
drive `R` down; `solve(dE=0)` on log+area is imaginary).
A discrete cycle plus a space-cost per contact **does** have
a finite minimizer, but `n*` **slides with** `ρ = β/α`. At
`ρ = 1`, even `n` ties 4 and 6. 1B states a trough *shape*
without writing `V(ρ)`. It does not state a trough *location*
without writing `ρ`. Writing `ρ` by hand is the imported well.

**1U.** Numbers pinned to PDG 2024 / CODATA 2022 / CREMA / SK /
Ji–Yang / DIS / AME2020. Classes unchanged. **No veto.**

Joint observation, recorded so it is not later sold as a
theorem: F-odd + F-3 forbids `n = 4`, so the `ρ = 1` tie
would pick `n = 6` / `K_{3,3}`. That is a **named reading**.
It is not ending A.

## 3. Which ending this is

**Not A.** 1A is a zoo, not a line.

**Not B.** 1A is discrete, not a continuum of sizes. A new
substrate is not forced, and is not authorized.

**Not D.** 1U found no veto.

**Not C, read strictly.** Ending C is a conjunction:
“cannot state a trough without importing `V(ρ)`” **and**
“1A has no unique lock.” 1B *can* state a trough mechanism
(`E = α E_w + β n`, `ρ > 0` ⇒ finite `n*`) without a hand
potential. 1A *has* unique smallests under named filters.
The stop clause does not fire.

**The decision is therefore none of the four slogans as a
substrate choice.** Phase 1 succeeds as an investigation:
the forced facts are written, the unforced ratio `ρ` is
named, the unfold filter is in force, and **no new kernel
is opened.**

That is a result. It is not a proton.

   (Face C, and 1B S1–S4).

   The set is a zoo.

   5-D or 7-D cell stage.

   close.

   an unforced conversion ratio `ρ`.
7. The world’s proton facts do not veto a lock-of-field
   thesis. They still require: coarse = one size, fine =
   field; p and n the same size; Higgs numbers on the

- `K_{3,3}` is a proton.
- `n* = 6` is derived.
- `ρ = 1` is law.
- A 5-D lattice would fix unique size.
- Phase 3 is authorized.

## 5. What Phase 1 authorizes next

**Phase 2 is authorized:** one size-spectrum *meter*, on
existing streams, no new law. The claim is line vs continuum
(or ceiling). The H0 targets named in the charter stand.

**Phase 3 is not authorized.** A dynamics face needs a rule
the meter can see *and* explicit user sign-off. 1C does not
name that face. It names the gap the face would have to
close: either force `ρ`, or state a different size selector
that 1A and 1B have not already refused.

**No substrate copy. No knob. Live code remains v97.**
The Phase 2 tool lives under `v98/` and *reads* `v97/hunt`.
It does not edit the kernel.

## 6. How to disagree with this page

To claim ending A: exhibit a filter that is already a
measurement (not a taste) and that leaves one graph per
allowed `n` past `n = 7`. F-odd+F-3 is not enough.

To claim ending B: show that C1–C3 plus the measured
filters produce a continuous family of sizes, not a zoo
of finite graphs. The atlas count says otherwise.

To claim ending C: show that `E = α E_w + β n` is secretly
an imported `V(ρ)`, *or* that unique-smallest under a
measured filter is not a lock candidate. Then the stop
clause would fire and Phase 2 would still be lawful as a
meter on old streams, but the programme would have no
size mechanism left to point a face at.

To claim ending D: name a PDG row that a lock-of-field
cannot say. None is on the ledger today.
