## 1. What Phase 3 is allowed to be

The charter (`README.md` §IV) opens Phase 3 only if
**Phase 1C named a rule the meter can see.** Then: one
face, one default-off knob, explicit sign-off, battery
green at 0. Either a closure-gated promotion **or** a
collapse step on the fiber. Not both.

**Bar:** the size histogram collapses to a line (or a short
discrete ladder), seed-robust. A tax-shaped pile-up is a
miss.

1C (`phase1/DECIDE.md` §5) did **not** name that rule. It
named a gap: force `ρ`, or state a selector that 1A and 1B
have not already refused. Phase 2 was authorized as a
meter so that, if a rule appeared, we could see it.

Phase 2 is done. The rule did not appear.

## 3. Why neither named face is a Phase 3

The charter listed two faces. Each is already in conflict
with a Phase 1 result that Phase 2 just *illustrated*.

### Closure-gated promotion

1A: cycle-closure (C1–C3) is a **zoo**, not a line
(577 types on `n ≤ 7`; Face C in vivo is that zoo at
`N ~ 10²–10³`). A door that fires only on 2-edge-connected
contacts would still admit the Face C giant — that component
*is* connected and bridgeless. The Phase 3 bar is collapse
**to a line**. 1A plus the Face C histogram predict a miss.

Tightening the gate to F-odd+F-3 (`K_{3,3}` at `n=6`) is
the named joint *reading*, not a derived rule
(`DECIDE.md` §2, §4). Implementing it would be adopting
`n*=6` by taste. 1C forbade that sentence.

### Collapse step on the fiber

1B: continuum 3+2 kinetics have **no trough**. A discrete
trough exists and **slides with unforced `ρ`**. Phase 2
cannot measure `ρ` (it is not a column in the FCS). A
collapse step that picks a radius is `V(ρ)` under another
name. 1C forbade writing `ρ` by hand.

Cadabra2 would not change this. There is no forced 3+2
action to vary.

## 4. What would make Phase 3 possible later

All three, not one:

1. A **rule** that 1A/1B have not already refused, written
   so the size meter can see its effect (a predicted line
   at a named `N` or a named Laplacian book).
2. That rule must **not** be “hold the painted C6” (already
   a line, already not a particle) and **not** “tax harder”
   (already a ceiling).
3. Explicit user sign-off on one default-off knob, both
   kernels or the Go-only scope the user names, battery
   green at 0.

Until (1) exists, “move to Phase 3” is a face without a
law. Phase 2 made that sharper: we can now *see* that Face
C is not a near-miss line. It is a different object. A
small gate will not turn it into `N=6`.
