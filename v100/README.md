## The energy

The frame on a link is an \(\mathrm{SU}(2)\) element. A hedgehog of
degree 1 is

\[
U = \cos F(r) + i\,\hat r\cdot\tau\,\sin F(r),
\quad F(0)=\pi,\quad F(\infty)=0.
\]

In the unit \(x = r/R_0\) with \(R_0 = \sqrt{B/A}\),

\[
E[F] = 2\pi\int_0^\infty\Big(
x^2 F'^2 + 2\sin^2 F
+ \sin^2 F\,\big(2 F'^2 + \tfrac{\sin^2 F}{x^2}\big)
\Big)\,dx.
\]

The first group scales as a length. The second scales as an inverse
length. A rank-1 wave (the slit) has a vanishing second group. This
functional is the Skyrme energy. Phase 0 adds no pion-mass term and
scans no coefficient. Whether one action quantum on each term still
sits above the grain is a phase-1 question, and only if the gates
pass.
