# v80 REPRESENTATION — Real substrate, locks, charts

## Thesis

Stop treating the world-step as “update \(\phi(x)\) on fixed \(x\)” (or N copies of that).  

Treat the world as:

```text
REAL  = FreeSubstrate + Locks
POV   = Charts { C, M, E, … } over the same state
EXPORT = optional projections (φ-grid, multi-fab SFA, volview, …)
```

- **Real:** free medium evolves; locks are sequestrations of free structure.  
- **POV:** every readable quantity is a chart (what is held const, what moves).  
- **Export:** multi-fab and Eulerian multiplet fields are **shadows**, not home ontology.

## Doctrine: reality as both real and a point of view

Not two worlds. One world, several **ledger gauges**:

| Chart | Hold “as if const” | Residual moves into | Preferred use |
|-------|--------------------|---------------------|---------------|
| **C** | free locality \(c\) | path cost / free measure \(\ell\); lock \(E,M\) | Physical free-frame law (v76) |
| **M** | rest-mass *label* of a lock | \(c_{\mathrm{eff}}\) / optical dual / energy table | Numerics on flat mesh; fixed inventory names |
| **E** | energy *budget* of a region | \(M_{\mathrm{eff}}=E/c^2\) and/or \(c_{\mathrm{eff}}\) | Budget boundaries; radiation honesty |

Schematic lock triple with \(E_\star = M_\star c_\star^2\): only two free; chart picks which dial is unit.

**Existence:** a lock exists if free substrate supports stable sequestration — not if a table holds \((M,E,c)\) with no medium.

**v76 kill still holds:** do not promote variable free-density GRIN as true free-vacuum gravity.  
**v80 add:** optical / \(c_{\mathrm{eff}}\) redraw may be a **legitimate M-chart view** of path measure, not the free-frame law.

## Kill gates for any candidate

A proposal **dies** if:

1. Primary state reduces to \(\phi(x)\) (or N copies) on fixed N³ with no free-structure dynamics.  
2. “Particle” is only a hump in \(\phi\) with no sequestration of free DOF / budget / measure.  
3. Charts C/M/E cannot be defined as re-partitions of one state.  
4. Opposite-charge binding requires hand-placed Q-balls as the *definition* of light sector.  
5. \(c\) is only a CFL parameter with no first-class causal budget or free-signal law.
