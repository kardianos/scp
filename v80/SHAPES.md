# v80 SHAPES — Candidate substrates

**Filter:** primary simulation state is **not** “another multiplet of continuum fields on a fixed Eulerian grid.”  
**Focus (user interest):** **3, 4, 6, maybe 10.**

## Focus set

### Shape 3 — Path-measure primary

| | |
|--|--|
| **State** | Path-cost measure \(\ell\) (or propagator / travel-time field); locks as sources that thicken \(\ell\) |
| **Step** | Free signals recompute weighted paths / hyperbolic free evolution on the measure; \(c\) fixed in C-chart |
| **Particle** | Stable source pattern in \(\ell\) with energy ledger \(E_\star\) |
| **Charts** | C: fixed \(c\), warp \(\ell\); M: fixed mass labels → optical \(c_{\mathrm{eff}}\) on flat mesh; E: fixed region budget |
| **Multi-fab shadow** | Lock *types* source \(\ell\) differently; shared free measure |
| **Risk** | Collapses to side Poisson after \(\rho_b(\phi)\) if \(\phi\) remains primary |

**Gets at:** monist “warp at fixed local \(c\)” as the **stored object**.

### Shape 4 — Dual substrate (free medium + locks)

| | |
|--|--|
| **State** | Two **kinds**: (A) free medium (graph / capacity / free gauge); (B) discrete locks (id, type, \(Q\), \(\omega\), \(E_\star\), …) |
| **Step** | Free medium updates; locks source medium; medium forces locks |
| **Particle** | Lock object, not a hump definitionally |
| **Charts** | C/M/E on lock ledgers + free stresses |
| **Multi-fab shadow** | Species of lock (bag / charge / light), one free medium |
| **Risk** | Becomes molecular N-body with hand potentials if free medium is fake |

**Gets at:** isolation as **type distinction**, not parallel arrays.

### Shape 6 — Update-budget monism (\(c\) literal)

| | |
|--|--|
| **State** | Per locus **update allowance** per tick; free influence spends budget |
| **Step** | \(c\) = max causal spend / hop per tick (engine law, not just CFL comment) |
| **Particle** | Lock **sequesters** update budget (inertia ≈ stuck updates) |
| **Charts** | C: global max budget fixed, who-touches-whom warps; M: sequestered label fixed; E: regional spend ledger fixed |
| **Risk** | Too metaphorical; must still couple to energy and charge ledgers |

**Gets at:** R1 as **literal step coin**.

### Shape 10 — Gauge / defect first

| | |
|--|--|
| **State** | Connections / links primary (or co-primary); matter = defects, windings, frustrated plaquettes |
| **Step** | Free gauge evolution; defects move / bind under free forces |
| **Particle** | Stable defect bundle |
| **Multi-fab shadow** | Defect species = charge / bag labels |
| **Risk** | Weak on mass/\(c\) unless paired with 3 or 6; still “physics-like” |

**Gets at:** charge dual without first-class \(\Phi\) as ontology.
